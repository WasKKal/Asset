# Lucide Icons for Roblox

Latest Lucide icon library (1756 icons) converted for Roblox.

## Files
- `lucide/init.lua` - Self-contained Lua module
- `lucide/sheet_0.b64` - Base64-encoded sprite sheet 0
- `lucide/sheet_1.b64` - Base64-encoded sprite sheet 1

## Usage
```lua
local Lucide = loadstring(game:HttpGet("https://raw.githubusercontent.com/WasKKal/Asset/master/lucide/init.lua"))()
local icon = Lucide.GetAsset("search")
```
