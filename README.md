# DeltaExecutor-UI Rebuild

为 **Delta 执行器（Roblox Executor）** 提供的 **UI 美化与重构项目**。

本项目对 Delta 执行器的主界面进行重写、美化与稳定性优化，目标是提供更干净、更抗检测（anti-cheat）的 UI 层，并保留可扩展的页面系统。

---

## 项目定位

这是一套 **UI 层** 项目，核心职责是界面渲染、布局、设置与页面托管，**不包含** 任何具体游戏作弊逻辑。为降低被反作弊（Byfron / Hyperion）检测与踢出的概率，已主动移除或弱化部分会触发检测的代码：

- 移除 `Anti-Kick`（hook `Player:Kick` 拦截踢出）
- 移除 `FPS 解锁`（`setfpscap`）与 `Anti-AFK` 的强模拟输入
- 移除自动重进 / 跳小服务器的 `TeleportService` 重进逻辑（改为手动提示）
- 全面使用 `gethui()` 隐藏挂载，避免 UI 被检测

## 目录结构

| 路径 | 说明 |
|---|---|
| `DeltaUI.txt` | 主 UI 脚本入口：加载页面、布局、设置、语言、危险功能分区 |

## 主要特性

- **隐藏挂载**：通过 `gethui()` 挂载 UI，规避检测
- **多语言**：翻译报错 + 手动切换 UI 语言
- **可切换布局**：选项卡栏支持左侧 / 右侧布局，最小化按钮随布局自适应定位
- **设置分区**：包含「危险功能」「页面扩展」等分区
- **远程安装**：「安装危险功能」按钮从远程下载脚本到本地并 `loadstring` 加载，按钮变红后可卸载
- **本地页面**：可将 `.lua` 页面放入 `DeltaUI/Pages/` 由主 UI 启动时自动加载（需符合页面注册规范）

---

## 使用说明

1. 将 `DeltaUI.txt` 作为主脚本加载。
2. 页面文件放在本地 `DeltaUI/Pages/`（以 `.lua` 结尾），重启 / 重新执行主 UI 后自动扫描加载。
3. 页面脚本需符合注册规范（`DeltaPageInfo` / `DeltaRegisterPage` 或 `return {name,title,icon,build}`），才会生成选项卡。
4. 「危险功能」分区中的「重新加入」按钮始终可用；「安装危险功能」按钮需在联网环境下从远程拉取脚本。
